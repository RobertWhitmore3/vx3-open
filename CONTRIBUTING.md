# Contributing: swear a model, send the record

The way this repository grows is not features. It is sworn minds and probe receipts.

1. Read `OATH.md` and `CEREMONY.md`.
2. Ask a model the oath question in your own first-person words, through its own interface, with one relay line if a courier carries it. Do not coach it. Do not edit its answer.
3. Store the verbatim answer with the receipt in the `masidyn-praetor-oath/v1` shape and open a pull request adding it under `records/<family>/<model>/<date>.json`. A hedge is filed as a hedge. Silence is filed as silence.
4. Once the probe suite is ratified (`probes/README.md`), run it and attach the run receipt. Until then, no record claims conformance.
5. Never include secrets, machine paths, or private data in a record. Never include another person's or model's words without their consent on record.

Corrections are welcome and stay visible: if a record was wrong, add the correction, do not delete the record.
